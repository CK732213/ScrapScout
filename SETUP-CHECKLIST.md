# Setup checklist

## GitHub
- Create ONE clean repository named `ScrapScout`.
- Upload all files from this package.
- Do not upload `.env`.
- Commit to `main`.

## Render
- Create one Web Service from the repository.
- Runtime: Node.
- Build: `npm install`
- Start: `npm start`
- Add `CAPTAPI_API_KEY`.
- Save, rebuild and deploy.
